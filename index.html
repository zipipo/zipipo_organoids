연구노트 프린트

선택한 작업 기록을 화면에 보이는 표 그대로(라인별 Date/Action/P·D/Plate/Ratio/Well/Stock/Memo), 실험노트에 오려 붙이기 좋게 폭만 줄여서 인쇄합니다. 인쇄(또는 PDF 저장) 후에는 자동으로 "인쇄됨"으로 표시되어, 다음번엔 아직 안 붙인 기록만 골라 이어서 뽑을 수 있어요.

현미경 사진 — 이름·스케일바 넣어 저장

사진을 여기로 끌어다 놓거나 클릭해서 선택
PNG / JPG / TIFF 지원 · 배율별 스케일바 자동 적용
· 사진마다 라인·배율을 고르면 날짜 기준 P / D 가 자동 계산되어 파일명이 만들어집니다.
· '스케일바 추가'를 켜면 배율에 맞는 100µm 스케일바가 사진에 그려져 저장됩니다. (끄면 이름만 바꿔 저장)
· TIFF 선택 시 — 스케일바를 끄면 원본 파일 그대로(이름만 변경) 저장돼 현미경에서 그대로 열립니다. 스케일바를 켜면 표준 RGB TIFF로 새로 저장됩니다.
· 촬영 순서 자동 적용이 켜져 있으면 사진을 추가하는 순서대로 라인·배율이 자동으로 채워집니다. 자동으로 채우고 싶지 않으면 꺼두세요.
· 사진을 지우거나 순서가 밀렸다면, 자동으로 다시 맞춰지지 않습니다 — 아래 목록 위쪽의 ↻ 순서 새로고침 버튼을 눌러야 남은 사진들이 순서에 맞게 다시 채워집니다.

사진 선택 → PPT 만들기

여러 폴더에서 사진을 골라 계속 추가한 뒤, 한 번에 PPT로 만듭니다.
· 규칙 이름 (날짜_환자_타입_pX_dY_배율)
  → 세로 4x / 10x / 20x, 가로 날짜 그리드 (열 위에 날짜·P·day·well·조건 헤더, 슬라이드당 5세트)
· 그 외 이름 (Image_0001 등) → "기타 이미지" 슬라이드에 3행 × 5열로 정리
결과는 YYMMDD Cell images (YYMMDD-YYMMDD).pptx (만든 날짜 - 사진 파일 날짜 범위) 파일로 다운로드됩니다. (PNG · JPG · TIFF 지원, 모든 브라우저)
사진을 여기로 끌어다 놓거나 클릭해서 선택
